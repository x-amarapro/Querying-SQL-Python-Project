# Querying SQL with Python

A data analysis project exploring the Chinook database using Python, SQLite, Pandas, and Matplotlib.

## Overview

This project demonstrates how to connect Python to a SQLite database, execute SQL queries, analyze relational data, and visualize query results.

Using the Chinook database, I explored sales data to answer three analytical questions:

1. What are the 10 best-selling tracks?
2. Which country generates the most revenue?
3. Which sales support representative is assigned the most customers?

## Technologies Used

- **Python** – Data querying and analysis
- **SQLite3** – Database connection and SQL execution
- **Pandas** – Data manipulation and DataFrame creation
- **Matplotlib** – Data visualization
